# python-beginner-projects
My beginner Python programs and practice exercises

About the Project:

This is my beginner Python project. It asks the user to enter two integers, calculates their sum, and displays the result.

Concepts Learned:

User input using input()

Type conversion using int()

Variables and arithmetic operations

Displaying output using print()

Example Output:

Enter the first number: 5
Enter the second number: 3
The sum = 8

How to Run:

Make sure Python is installed on your computer.

Download the sum_of_two_numbers.py file.

Open a terminal in the file's folder.

Run the command:

python sum_of_two_numbers.py
